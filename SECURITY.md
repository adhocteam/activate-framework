# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this repository, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, please email us at <security@adhocteam.us> with:

- A description of the vulnerability
- Steps to reproduce the issue
- Any potential impact you've identified

We will acknowledge receipt within 3 business days and provide an initial assessment within 10 business days.

## Scope

This repository contains guidance files (Markdown), instruction sets, and prompt definitions. It does not contain executable application code. Security concerns are most likely to involve:

- Accidentally included secrets, tokens, or credentials
- Links or references that expose private infrastructure details
- Guidance that could lead to insecure practices if followed

## Supported Versions

We address security concerns in the latest version on the `main` branch.
